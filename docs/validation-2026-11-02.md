## Оставшаяся научная граница

Нужна отдельная проверка полного пути «история → оценённые допустимые duals →
поддержанная карта ставок → первая ставка → результат при бюджетном/CPC-критерии».
Текущие scalar-state симуляции задают качество инициализации искусственно, а
warm-start mismatch использует известную метку сценария. Их положительный
результат не устраняет отрицательный результат публичного BAT replay.
