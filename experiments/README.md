# Experiments

Start at the [repository README](../README.md): edit [`config.yaml`](../config.yaml),
run `python -m experiments`, and open the gallery printed at completion.

`warm_start.py`, `supported_bridge.py`, and `bat_calibration.py` are aliases for
running one task. `results/` contains the paper's reference artifacts; new runs
go to `outputs/` by default. See the [reproduction guide](../docs/reproducing.md)
for parameters, data paths, and supplementary tools.
